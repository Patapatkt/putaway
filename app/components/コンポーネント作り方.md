① 子で必要なものをimportする

string・`number` など、最初から使える型はimport不要です。別ファイルで定義した Product などを使う場合に読み込みます。
import type { Product } from "@/app/model/product";

今回の日時の例では、`string` だけなので不要です。

② 親から受け取るpropsの型を定義する
type XxxProps = {
    date: string;
};

③ 子コンポーネントの関数を定義し、④ JSXを返す

この２つは、同じ関数の中に書きます。
export default function Xxxx({ date }: XxxProps) {
    return (
        <span>{date}</span>
    );
}

「親で呼び出す関数」という理解で大丈夫ですが、正確には親のJSX内で使う子コンポーネントを定義する部分です。

⑤ 親でimportし、値を渡す
import Xxxx from "./components/Xxxx";

親のJSX内に書きます。
<Xxxx date={date} />

ここで、左右の date は役割が違います。
<Xxxx date={date} />
//    ↑      ↑
// 子のprops名  親にある変数

名前が違っていても渡せます。
<Xxxx date={lastReceivedAt} />

親の lastReceivedAt を、子では date という名前で受け取るという意味です。
